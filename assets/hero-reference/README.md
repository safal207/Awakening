# Референсы героя «Пробуждения»

Пакет добавлен 11 сентября 2026 года с разрешения владельца фотографий.

- `photos/`: четыре исходных фотографии пользователя для портретного сходства.
- `models/awakening-hero-v3.blend`: редактируемая сцена Blender.
- `models/awakening-hero-v3.fbx`: экспорт для последующей проверки в движке.
- `models/awakening-hero-v3.glb`: экспорт модели с материалами.

Это промежуточная v3. Художественная приёмка и проверка импорта v3 в Unreal
не завершены; герой в игре этим пакетом не заменяется. Результаты проверки v2
нельзя считать результатами проверки v3.

Копии сверены с локальными исходниками по SHA256. Локальный манифест с абсолютными
путями пользователя в пакет не включён.

Происхождение базовых ресурсов и ограничения описаны в
[документации модели](../../docs/HERO_ASSET_PIPELINE.md).
Личные фотографии не предоставляются по лицензии MIT исходного кода проекта.
Размещение в репозитории само по себе не предоставляет лицензию на их повторное
использование.
