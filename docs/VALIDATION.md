# Проверка графического обновления

Этот отчёт относится к первой итерации графики. После расширения улиц, новых
материалов и теней актуальные проверки ведутся в [MANHATTAN_REFRESH.md](MANHATTAN_REFRESH.md).
Исторические измерения ниже не следует приписывать второй итерации.

Дата: 10 сентября 2026 года. Проверялась Release-сборка с человеческой моделью,
новой геометрией города, освещением и MSAA 4x. Все команды запускались локально.

Сценарий делает десять снимков, включая отдельные экраны настроек и развязки.

## Профиль новой графики

Фиксированный seed 424242, 50 жителей, 1280x720, VSync выключен, MSAA 4x.
GPU: AMD Radeon(TM) Graphics, OpenGL 3.3 Core, драйвер 22.40.76.230711.
Автоматическое движение камеры и героя; прогрев включён в статистику.

| Метрика | Измерение за 120 секунд |
|---|---|
| Штатное завершение | Да, Interrupted=false |
| Реальное время | 120,07 с |
| Кадры | 7 523 |
| Средний FPS | 62,69 |
| Медиана кадра | 14,93 мс |
| p95 / p99 | 23,62 / 35,37 мс |
| Максимум | 163,11 мс |
| Выделения основного потока | 718 байт/кадр |
| Управляемая память: начало / конец / пик | 9,71 / 9,55 / 11,35 МиБ |
| GC Gen0 / Gen1 / Gen2 | 14 / 13 / 1 |
| Собственные GPU-буферы: конец / пик | 37,14 / 37,14 МиБ |

Пять системных замеров примерно с 77-й по 117-ю секунду процесса:
dedicated около 39,3 МиБ, shared 92,3-96,8 МиБ, последний shared 95,7 МиБ.
Это реальные счётчики процесса Windows, но только часть интервала, не непрерывная
трасса и не доказательство отсутствия утечек. На встроенном GPU shared - системная
память, используемая графикой. Её нельзя складывать с оценкой буферов как
независимые категории.

Сырой обезличенный отчёт: [runtime-120s.json](measurements/runtime-120s.json).
Системные замеры: [gpu-memory.csv](measurements/gpu-memory.csv).

**Цель p95 до 16,7 мс пока не достигнута.** Средние 62,7 FPS не означают
стабильных 60 FPS. Для следующей оптимизации нужны отсечение невидимого города,
проверка очереди загрузки динамических буферов и отдельный CPU/GPU-профиль.

Короткий диагностический прогон на 30 секунд ранее показал 87 FPS и p95 15 мс.
Он охватывает меньше состояний мира и не заменяет длинный результат выше.
Первый 120-секундный запуск не завершился штатно и показывал аномально высокую
shared-память; он остановлен и исключён из результатов. Точная причина не
доказана. После фиксации размеров окна, добавления тайм-аута и пропуска обновлений
при сворачивании повтор завершился штатно. Это наблюдение, не доказанный диагноз.

## Ограничения

- Новый 10-15-минутный прогон после изменения всей графики ещё не выполнялся.
  Ранее собранные длительные результаты относятся к другой графике.
- Окружение рабочего компьютера не было полностью изолировано от других задач.
- Не измерены GPU timestamp кадра и все выделения всех потоков.
- Нет доказательства отсутствия долговременной утечки или всех задержек.
- Физический геймпад, несколько мониторов и DPI 150/200% не проверены.
- Smoke-тест не доказывает корректность всего сюжета и всех комбинаций сохранений.
- Нет сетевого теста: сервера и совместной игры пока нет.
- Интерьеры пока без полноценных коллизий мебели; город архитектурно повторяется.
- Нужны тесты полного постоянного состояния NPC, миграций и повреждённых сохранений.

## Воспроизведение

Из корня репозитория:

```powershell
dotnet build Probuzhdenie.csproj -c Release
dotnet run --project Probuzhdenie.csproj -c Release -- --functional-test
dotnet run --project Probuzhdenie.csproj -c Release -- --self-test
dotnet run --project tests/GraphicsSmoke/GraphicsSmoke.csproj -c Release
dotnet run --project Probuzhdenie.csproj -c Release -- --runtime-profile --profile-seconds=120
```

Запускайте графический сценарий и профиль по очереди. Для расширенного 15-минутного
замера укажите `--profile-seconds=900`, отдельно снимайте системные GPU-счётчики.
Подробнее: [GraphicsSmoke](../tests/GraphicsSmoke/README.md).
