# Герой: обновление геометрии

Проверено 10 сентября 2026 года. Изменения локальные, без новых внешних моделей,
текстур, библиотек или переноса образа конкретного актёра.

## Что изменилось

- Отдельная геометрия героя использует общий рендер города и портрета меню.
  Прежняя геометрия прохожих сохранена.
- Корпус и голова построены по непрерывным сечениям: сформированы грудь, плечи,
  подбородок и челюсть, уменьшена открытая часть шеи.
- Обновлены глаза, нос, брови и причёска с боковым пробором; добавлено моргание.
- Рабочая рубашка получила карманы, планку, ручку, небольшую нашивку и задний шов.
  Для накладывающихся деталей разнесена глубина, устранено мерцание карманов.
- Добавлены ладони с отдельными слегка согнутыми пальцами, часы и рабочие ботинки
  с подошвой. Палитра героя отличается от случайной палитры прохожих.
- Сетка брюк непрерывна через колено. Новая поза шага сохраняет длины сегментов
  ног и опору хотя бы одной стопы на плоской поверхности.
- Контуры сечений рассчитаны заранее, промежуточный массив переиспользуется.
  Дальний герой получает менее подробный контур без мелких деталей.

Основные файлы: `src/FreeCity/CharacterMesh.Hero.cs`, `HeroPose.cs`, `HeroStyle.cs`.
Подключение к существующему рендеру находится в `CharacterMesh.cs`.

## Проверки

Release-сборка, функциональные тесты и сборка запуска прошли. Добавлены проверки:

- 64 фазы шага при трёх значениях смешивания движения: постоянные длины костей,
  отсутствие проникновения стопы под плоскость и наличие опорной стопы.
- Конечные координаты и наружные грани во время шага и моргания на всех трёх
  уровнях детализации; существующий тест проверяет перенос и поворот нормалей.
- Отсутствие влияния деталей героя на следующую модель прохожего.
- Нулевые выделения памяти при повторной сборке геометрии после прогрева.

Графический тест открыл настоящее окно игры, снял 11 сцен, проверил пиксели
портрета, ввод меню, вращение, размеры окна, тени и ошибки OpenGL. Проверены
разворот спереди/сбоку/сзади/в шаге, крупный план лица, меню, город и интерьер.
Это кадры движка, не отредактированные изображения. Личные сохранения при
графической проверке не используются.

Воспроизведение из корня проекта:

```powershell
dotnet run --project Probuzhdenie.csproj -c Release -- --functional-test
dotnet run --project tests/GraphicsSmoke/GraphicsSmoke.csproj -c Release -- --hero-qa
dotnet run --project tests/GraphicsSmoke/GraphicsSmoke.csproj -c Release -- --mesh-benchmark --hero-qa
```

Результаты создаются локально в `artifacts/hero-refinement`:
`hero-turnaround.png`, `hero-face.png`, `menu-1280.png`, `hero-city.png` и другие
кадры. Исходный `artifacts/hero-qa/hero-turnaround.png` оставлен для сравнения.
Артефакты не являются обязательными файлами репозитория и воспроизводятся тестом.

## Производительность

Новая подробная модель в неподвижной позе: 13 638 вершин, ниже проверяемого
предела 15 000. Короткий CPU-тест 50 жителей, 120 кадров с уровнями детализации:

| Показатель | До изменения героя | После |
|---|---:|---:|
| Вершины всех жителей | 128 184 | 131 418 |
| Медиана построения сеток | 9,936 мс | 9,764 мс |
| p95 построения сеток | 13,895 мс | 15,352 мс |
| Выделения всей тестовой обвязки | 4 800 байт | 4 800 байт |

Это короткие последовательные измерения, не доказательство ускорения. Сам
генератор после прогрева выделяет 0 байт по отдельному функциональному тесту;
показатель обвязки не следует выдавать за выделения одного героя.

Отдельный активный runtime-прогон: 60,001 с, 4 869 кадров, окно не сворачивалось.
AMD Radeon(TM) Graphics, OpenGL 3.3, 1280x720, 50 жителей, MSAA 4x, VSync выключен.

| Показатель | Результат |
|---|---:|
| Средний FPS | 81,15 |
| p50 / p95 / p99 кадра | 11,92 / 15,05 / 18,88 мс |
| Максимальный кадр | 455,37 мс |
| Выделения основного потока | 634,75 байта/кадр |
| Собственные GPU-буферы, пик | 133 913 976 байт |
| Собственные GPU-текстуры, пик | 25 163 968 байт |

Отчёт: `artifacts/hero-refinement/runtime-60s.json`, `Interrupted=false`.
Причина отдельного длинного кадра этим замером не установлена. Реальная память
драйвера dedicated/shared в этом прогоне отдельно не измерялась. Минутный тест
не подтверждает отсутствие утечек на длинной игровой сессии.

`visual-profile.json` от снимков содержит 0 кадров профилирования и не является
результатом замера производительности.

## Ограничения

Это улучшенная стилизованная процедурная модель, не фотореалистичный персонаж.
Полноценная мимика, скелет для импортированных анимаций, захваты предметов и
адаптация стоп к лестницам/неровной земле не добавлены. Наличие опоры на плоской
поверхности не доказывает отсутствие скольжения стоп в мировых координатах при
любой скорости. Коллизии города и механики памяти этим изменением не исправлялись.
