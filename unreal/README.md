# «Пробуждение»: Unreal-прототип

**Статус: исходники подготовлены, но в Unreal не собраны и не проверены.**
Unreal Editor и Epic Games Launcher не найдены в стандартных папках и записях
установки этой машины. Ничего не скачивалось, лицензии не принимались.
Текущая C#-игра в корне остаётся рабочим отдельным прототипом.

Это не готовый перенос игры и не фотореалистичная сборка. Здесь нет готовой
человеческой модели, сюжетного цикла, меню, NPC, сохранений или сетевой игры.
Старые сохранения не читаются и не изменяются. Скриншоты старого OpenTK-движка
не являются изображениями Unreal.

## Что подготовлено

- Отдельный C++-проект для **UE 5.7**, без зависимости от C#-рендера.
- Настройки Lumen с программной трассировкой, Virtual Shadow Maps и TSR.
  Аппаратная трассировка отключена; это не гарантия работы на встроенной графике.
- Генератор тестовой улицы длиной 120 м: проезжая часть 12 м, тротуары по 3 м,
  восемь объёмов зданий, лавки, ограничители движения и видимые границы сцены.
- Дневное солнце, Sky Atmosphere, захват небесного освещения, объёмный туман,
  начальная экспозиция EV100 13. Картинка ещё не проверена.
- Восемь базовых материалов с физическими параметрами. Пока это одноцветные
  материалы и простые формы, **не** сканированные фасады, стеклянные интерьеры
  или готовая художественная сцена. Nanite-ресурсы не импортированы.
- Character Movement, капсула роста 180 см, ходьба 1,65 м/с и бег 4,2 м/с,
  Spring Arm с проверкой препятствий. Проверка настоящих столкновений впереди.
- Enhanced Input и камера вокруг героя. WASD, мышь, Shift, Space, колесо,
  C возвращает камеру за спину; Esc завершает тест в редакторе.
- Заготовка `BP_Hero` для полноценного персонажа. До подключения модели видна
  диагностическая капсула, а не «новый реалистичный герой».

Погода, ветер, облака, жители кафе и окон пока не реализованы.

## Первый запуск

1. Установить Unreal Engine **5.7** через официальный Epic Games Launcher.
   Нужны C++-компоненты Visual Studio 2022 и Windows SDK. Установка Build Tools
   обнаружена в `C:\BuildTools`, но соответствие всей цепочки UE не проверено.
2. Из папки репозитория выполнить проверку, затем сборку и создание улицы:

```powershell
powershell -File unreal/prepare.ps1 -CheckOnly
powershell -File unreal/prepare.ps1 -BuildScene
powershell -File unreal/prepare.ps1 -Open
```

При нестандартной установке добавить `-EngineRoot 'D:\Epic Games\UE_5.7'`.
Скрипт не устанавливает программы, не меняет версию проекта и не удаляет файлы.
UE 5.7 выбран как фиксированная целевая версия, а не как утверждение о самой
новой версии движка. Переход на другую версию требует отдельной проверки.

Генерация запускается в отдельном процессе редактора и создаёт
`/Game/AwakeningPrototype/Maps/MeraStreet`. Повторная генерация останавливается,
если каталог ресурсов уже существует, чтобы не затереть ручную работу.
После ошибки могут остаться частично созданные ресурсы: сначала изучить лог,
затем работать с копией проекта или вручную переименовать этот каталог.
Отчёт `Awakening/Saved/AwakeningBootstrap.json` подтверждает только завершение
генерации, **не** корректность изображения, анимации или производительности.

Редактор и компилятор здесь не запускались. `.umap` и `.uasset` появятся только
после успешной генерации в настоящем Unreal. Покупные наборы не включены.

## Герой и реализм

Не переносим старую составную модель в качестве финального человека.
Художественная задача: собственное лицо, около 35 лет, 178-180 см, умеренная
асимметрия лица, короткие тёмные волосы, рабочая куртка серо-зелёного цвета,
светлая футболка, потёртые рабочие брюки. Силуэт и одежда отличаются от фильма.
Образ не должен воспроизводить лицо, голос или совокупность признаков актёра.

1. Создать оригинального MetaHuman либо приобрести/изготовить лицензированного
   человека. Проверить условия для модели, волос, одежды, текстур и анимаций;
   внести происхождение каждого ресурса в `ASSETS.md`.
2. Для единого skeletal mesh назначить Mesh и совместимый Animation Blueprint
   в `BP_Hero`. Смещение по Z и поворот в коде рассчитаны на вертикальный
   UE-совместимый скелет; проверить стопы, рост и оси конкретного ресурса.
3. Для MetaHuman перенести в `BP_Hero` **весь** набор компонентов тела, лица,
   волос и LODSync по документации Epic. Одного назначения Body недостаточно.
   MetaHuman-плагин не включён автоматически и ресурсы человека не загружены.
4. Настроить ретаргетинг ходьбы, бега, остановки, поворота и дыхания; затем
   Foot IK, контакт стоп, моргание и взгляд. Это ещё не реализовано.
5. Сделать реальные кадры лица и четырёх ракурсов в нейтральном дневном свете,
   затем проверить в движении на тротуаре и при входе в помещение.

Восьми зданиям нужны модульные фасады, правдоподобная толщина стен, двери,
оконные откосы и интерьер кафе. Сначала довести один угол улицы, затем расширять
район. Повторение тысяч кубов с Lumen не заменит художественную работу.

## Порядок работы

| Этап | Результат и критерий |
|---|---|
| U0: запуск | Сборка, генерация карты, успешный запуск Play в UE |
| U1: человек | Оригинальный персонаж, стопы без скольжения, лицо и 4 ракурса |
| U2: один угол | Готовые фасады, асфальт, кафе; дневной и вечерний кадры |
| U3: физика | Стены, скамьи, двери, NPC, лестницы, камера у углов; без прохода насквозь |
| U4: живой район | Ветер, облака, дождь, сухие/мокрые материалы, жители и расписания |
| U5: игра | Перенос цикла Сверки и памяти с тестами, отдельно от графики |
| U6: бюджет | 15 минут: CPU/GPU frame time, p95/p99, VRAM, память, загрузка |

Это не замена основному `ROADMAP.md` и не заявление, что его этапы закрыты.
Онлайн не появляется автоматически от использования Unreal.

## Проверки

```powershell
python -B -m unittest discover -s unreal/tests -v
dotnet run --project Probuzhdenie.csproj -c Release -- --functional-test
```

Первый набор проверяет только структуру проекта, синтаксис Python, геометрию
плана и статический запас места для капсулы. Он не импортирует модуль `unreal`
и не проверяет C++-компиляцию, реальные столкновения или рендер.
Второй проверяет прежнюю игру и не служит тестом Unreal.

После установки: собрать Editor, создать карту, запустить Play, проверить
направления управления и камеру; затем персонажа и материалы при 1280x720 и
1920x1080. Для профиля использовать `stat unit`, `stat gpu`, `stat RHI`, Unreal
Insights и `memreport -full` до/после 15 минут. Компиляцию шейдеров отделять от
прогретого игрового замера. Текущие 720p/High/60 FPS являются стартовыми
настройками, **не измеренным результатом**. На найденной ранее AMD Radeon
Graphics нельзя обещать Lumen 60 FPS без проверки модели GPU и драйвера.
